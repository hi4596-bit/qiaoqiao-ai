# 乔侨爱学习 · 风格自训练

**一句话**：把业务表格扔进来，脚本自动拆出「每个人 / 每个账号」的口播风格卡 + 可检索语料库；以后说「按 XX 的风格写 3 条」，就读那张卡出稿。每个人都可以加自己的风格，互不覆盖。

> 本技能学的是**怎么写**（语感、结构、体例、标题习惯），**不学数字**。数字一律以用户当次给的官方表为准——脚本会把语料里的数字标成「观察值/非官方口径」，并在 `check` 里对「语料里没出现过的新数字」报警。

## 目录

- `scripts/qiaoqiao.py` —— 训练 / 检索 / 自检脚本（纯本地，不联网、不调模型、不改原表）
- `scripts/make_template.py` —— 生成空白业务表模板，给同事填自己的稿
- `templates/我的风格-模板.xlsx` —— 现成的空白模板（8 列体例 + 账号配置区）
- `sources/` —— 首次训练用的原始语料（xlsx + 打包说明），便于复训
- `learned/styles.json` —— 风格索引（多风格注册表）
- `learned/overview.md` —— 总览表（人看）
- `learned/cards/<风格>.md` —— 每个风格一张**风格卡**（写稿前必读）
- `learned/corpus/<风格>.jsonl` —— 该风格的逐篇语料（原文，按表头字段存）
- `learned/learn-log.jsonl` —— 每次训练/自检的留痕
- `references/表格式说明.md` —— 支持的表格列体例（8列/11列/兜底）

## 命令速查

脚本由 **DSH 运行时的内置 Python** 执行（已含 openpyxl，无需安装）。让 AI 帮你跑时直接说“学习一下这张表”即可；自己手动跑时，把下面命令里的 `python` 换成你的 DSH 内置 Python 完整路径（每台机器不同，一般在 `C:\Users\<用户名>\.dsh\dsh-runtimes\...\dependencies\python\python.exe`），或任意装了 `openpyxl` 的 `python3`。

```bash
# 1) 喂表训练
python scripts/qiaoqiao.py learn "路径/业务表.xlsx"
#    → 默认：每个 sheet 各训练成一个独立风格（推荐，账号天然分开）
python scripts/qiaoqiao.py learn "路径/业务表.xlsx" --style "乔侨爱学习" --owner "乔侨"
#    → 整张表合并成「一个人」的风格
python scripts/qiaoqiao.py learn "新表.xlsx" --sheet "文老师升学历"   # 只补一个 sheet
python scripts/qiaoqiao.py learn "新表.xlsx" --replace                # 同名风格重建（默认增量合并+按正文哈希去重）

# 2) 看
python scripts/qiaoqiao.py list
python scripts/qiaoqiao.py show "文老师升学历"
python scripts/qiaoqiao.py topics "文老师升学历"     # 选题库查重

# 3) 写完稿自检
python scripts/qiaoqiao.py check "草稿.txt" --style "文老师升学历"
#   → 校验：首句钩子、字数是否落在该风格「中位±25%」区间（偏短/偏长都会提示）、
#     广告法禁用词命中（否定句也算）、以及「语料里没出现过的新数字」（必须回官方表核对）
#   → 通过也会提示「仍须人工核对事实口径」，脚本不替你担保数字对错

# 4) 删（只删训练成果，不动原表）
python scripts/qiaoqiao.py forget "风格名"

# 5) 给同事发一张空白表（可指定输出路径和 sheet 名）
python scripts/make_template.py "我的风格-模板.xlsx" "我的风格"
```

支持 `.xlsx/.xlsm/.csv/.tsv/.jsonl`；老 `.xls` 会明确提示「另存为 .xlsx」，不假装读过。没标准表头时自动退化成「最长文本列 = 口播正文」，并在卡片里写明降级说明。

## 写稿流程（按某人的风格）

1. `list` 确认风格存在；`show <风格名>` 读完整风格卡。
2. `topics <风格名>` 拉选题库，选一个**不重复**的切口（用户没给角度时自选）。
3. 按风格卡出稿，重点对齐：人称身份、钩子句式、字数区间、分段/分点方式、结尾类型、三平台标题习惯、固定话题标签。
4. **数字**：先问用户/查当次官方表；语料里的数字只能当「曾经出现过」，绝不能当权威。广开/国开魏老师风格稿请改用 `guokai-script` 技能及其 `facts-and-fees.md`。
5. 把稿存成 txt，跑 `check 草稿.txt --style <风格名>`；命中禁用词/新数字/字数越界就改到干净。
   - 字数判据是「该风格语料**中位字数 ±25%**」带（不是死卡最短值），偏短或偏长都会给方向性提示。
6. 交付：用户要表格时按该账号原表体例（8 列）或 `guokai-script` 的 11 列体例输出；表头一字不改。

## 口径隔离（重要，别串味）

工作区里有两套成稿，事实口径不同，**不要混用**：

| | 本技能（新六体 / 各账号风格） | `guokai-script`（魏老师风格） |
|---|---|---|
| 人称 | 第三人称「老师」讲给同学听 | 第一人称「同学们，我不允许…」 |
| 畜牧兽医学费 | 3420 元/年、只收 2 年、直接交学校 | 3420 元/年、分 3 次交 |
| 广开学费 | 按语料/当次官方表 | 7455/8591/6840/7904，分 3 次交 |
| 小自考 | 强调 30% 助学加分 | 按该技能口径 |
| 数字权威 | 用户当次给的官方表 | `references/facts-and-fees.md` |

用户没说用哪套时，先问一句「按哪个账号 / 哪套口径写」。

## 加自己的风格（给同事的话）

1. 直接复制 `templates/我的风格-模板.xlsx` 填成稿（一个 sheet = 一个账号/一个人的风格；列至少要有「完整口播脚本」，最好有「3秒爆点开头 / 选题方向 / 抖音标题 / 小红书标题 / 视频号标题 / 发布文案」）。或跑 `make_template.py` 现生成一张。
2. 跑 `learn 你的表.xlsx --owner 你的名字`，脚本自动出卡，不碰别人的卡。
3. 以后写稿说「按我的风格写 3 条」即可。补新稿再跑一次同名 `learn` 就是增量合并（按正文哈希去重）；想推倒重来加 `--replace`。
4. 表头认不出来也能跑（按最长文本列当正文），但卡片里会写「部分字段留空」——补齐表头能学到更全的标题/标签习惯。

## 边界

- 只读原表，不写回、不上传、不联网。
- 不生成图片/视频、不发布、不写飞书表（本环境没挂载 sheet 工具时改为交付本地表格）。
- 风格卡里的「高频数字 / 业务实体词频」是从成稿数出来的观察值，可能含作废口径，写新稿必须回官方表核对。
- 训练成果是明文语料，含业务话术；放进共享/公开目录前自己把关。
