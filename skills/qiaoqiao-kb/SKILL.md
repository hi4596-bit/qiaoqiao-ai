# 乔侨爱学习 · 业务知识库（官方口径底表）

**一句话**：这是从《2026年班主任工具清单》里抽出来的**官方事实库**，不是口播稿、不做风格训练。凡是写稿或回答学生时要填**学费、学制、学位条件、备案关系**，以这里为准。

> 和 `qiaoqiao-style`（风格卡）的关系：风格卡只管「怎么写」，数字标成观察值；本库管「写什么数字」。**写新稿 = 风格卡定调子 + 本库填事实**。两套成稿口径（魏老师版 guokai-script / 新六体版 qiaoqiao-style）里的数字，凡与本库冲突，一律以本库（当次官方表）为准。

## 目录

- `scripts/build_kb.py` —— 把班主任工具清单 xlsx 抽成知识库（纯本地，不改原表）
- `sources/班主任工具清单.xlsx` —— 原始底表（26.8.12 更新）
- `kb/kb.json` —— 结构化事实（机器可读）
- `kb/kb.md` —— 人读索引（关键数字 + 学校政策速查）
- `kb/kb_raw.md` —— 逐 sheet 原文（结构化漏了的在这里兜底查）

## 知识库覆盖（构建结果）

- **招生简章 734 条**：成考（专升本/高升专高升本，338+152+130）、国开 46、广开 24、自考 44，按 院校/层次/专业/学制/学费/考试科目 结构化
- **学位申请条件 63 条**：每校的 学位外语/各科目成绩/学位论文成绩/答辩 要求
- **学位英语报考条件 15 条**：各校 学位英语/自考英语二/PETS/校内四六级/TEM4/TEM8 报考与替代规则
- **本科论文与延毕 15 条**：论文写作次数、实践报告、是否可延毕、休学限制、学籍年限
- **备案教学点 7 条**：教学中心（如越秀易普、天河侨大、未来教育）↔ 高校 的备案关系
- **工具清单 15 条** + **操作 SOP**（成考辅导班电子协议、美团/大众点评好评步骤）

## 怎么用（给 AI 的查表步骤）

写稿/答问前，需要事实时：

1. **先读 `kb.md`** 看人读索引（数字都在里面，直接抄）。
2. 索引里没有的（如某专业具体考试科目），**再查 `kb.json`**：
   ```bash
   python -c "import json; d=json.load(open(r'...qiaoqiao-kb\kb\kb.json',encoding='utf-8')); print([r for r in d['招生简章'] if '畜牧兽医' in r.get('专业','')])"
   ```
3. `kb.json` 仍缺（表结构异常/多值堆叠），**查 `kb_raw.md`** 看原表逐行。
4. 关键数字（学费/学制/学位线）**一律以 `kb.md` / `kb.json` 为准，不要凭记忆或从成稿观察值推断**。

## 复训 / 更新

底表每季度可能更新（文件名带日期）：
```bash
python scripts/build_kb.py "新班主任工具清单.xlsx"
# 或直接覆盖 sources/ 同名文件后：python scripts/build_kb.py
```
重建后会刷新 `kb/kb.json`、`kb/kb.md`、`kb/kb_raw.md`，不碰任何成稿或风格卡。

## 边界

- 只读原表、不写回、不上传、不联网。
- 知识库里的数字来自 26.8.12 版底表，若学生问的是最新政策，仍需回官网/当次通知核对（表内多处注明「以当年招生简章/文件为准」）。
- `kb_raw.md` 与 `kb.json` 含业务全量数据（院校、学费、政策），放进共享目录前自己把关。
